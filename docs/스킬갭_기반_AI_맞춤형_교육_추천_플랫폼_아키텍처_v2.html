MASTER ARCHITECTURE SPECIFICATION v6.5 (FULL VECTOR RAG EVOLUTION EDITION)

스킬-갭 및 Full-Spectrum Vector RAG 기반 AI 추천 플랫폼 마스터 아키텍처 명세서

CORE ARCHITECTURE 3-LINE SUMMARY
  1. 전 도메인 벡터 인덱싱: 5대 핵심 도메인(강좌 56건, 도서 38권, 자격증 29종, 학과 8개, 직무 8개)과 36개 스킬 전수를 text-embedding-3-small(1536차원)로 사전 벡터화하여 Supabase pgvector(HNSW 인덱스)에 영구 동기화했습니다.
  2. 10ms 초저지연 시맨틱 인출: 런타임 GPT 호출 지연(2~3초)과 가짜 링크(Nginx 500 에러)를 영구 퇴출하고, DB 로컬 코사인 거리(<=>) 연산만으로 결손 역량에 최적화된 실재 콘텐츠를 10ms 만에 100% 충원(Strict 2-Pack)합니다.
  3. Zero-Hallucination 로드맵 조립: RAG 엔진이 선별한 100% 검증된 실재 메타데이터만을 Ground Truth 컨텍스트로 GPT-4o에 주입하여, 환각 없는 맞춤형 학습 마일스톤과 단계별 성장 시퀀스를 렌더링합니다.

36개 표준 실무 스킬을 100% 커버하는 엔터프라이즈 실재 카탈로그(도서 38권·강좌 56개·자격 29종), 공공데이터 K-MOOC v2.0 정규 파서 및 ODCloud 동적 연동, PostgreSQL pgvector 1536차원 HNSW 코사인 유사도 인출 엔진, 그리고 자가 검증 감사 매트릭스(Coverage Matrix)를 규격화한 종합 마스터 설계 명세서입니다.

0. 핵심 엔지니어링 의사결정 배경 (Architectural Decision Records)

사내 HR 직무 역량 강화 플랫폼 환경에 맞추어 채택한 프로덕션 레벨의 8대 기술적 의사결정 기록(ADR)입니다.

1. Full-Spectrum Vector RAG 전환

런타임 GPT 프롬프트 호출의 느린 속도(2~3초)와 JSON 깨짐을 영구 폐기하고, Supabase pgvector 코사인 거리(<=>) 연산으로 10ms 만에 최적 콘텐츠를 인출합니다.

2. 가짜 강좌 ID 박멸 & 100% 실재 링크

Nginx 500 오류를 내던 가상 검색 URL과 가짜 ID(21314_DK 등)를 완전 소거하고, K-MOOC v2.0 API의 실제 개설 ID 기반 detail/{id} 링크만 100% 보장합니다.

3. 공인 자격증 마스터 과목 보호

[PG] 등 공공 API 행정 불용어를 세척하고, 빅데이터분석기사 등 23대 마스터 자격증의 출제과목이 API 기본값으로 오염되지 않도록 단방향 업데이트 격리를 확립했습니다.

4. 미승인 API 격리 (Feature Flags)

도서관 정보나루와 커리어넷은 paths.yaml의 기능 플래그로 격리하여, 추후 API 승인 시 소스 수정 없이 실시간 API 모드로 1-Click 자동 전환되도록 조치했습니다.

5. 직무 ↔ 스킬 동적 바인딩 (Cascading)

사내 목표 직무 선택 시 job_skill_map에 매핑된 필수 실무 역량만 UI에 동적으로 필터링하여 직무-스킬 도메인 붕괴를 원천 방어했습니다.

6. 학위(is_degree) & Gap 심각도 분기

일반 임직원에게는 학과를 숨기고 실무에 집중하며, HIGH Gap은 4단계 풀트랙($A \to D$), LOW Gap은 2단계 패스트트랙($C \to D$)으로 동적 렌더링합니다.

7. 런타임 추가 비용 $0 (1회 배치 임베딩)

매 요청마다 과금되는 LLM 프롬프트 대신, 파이프라인(main.py 1) 실행 시 1회만 임베딩을 생성해 pgvector에 영구 적재함으로써 운영 비용을 0원으로 수렴시켰습니다.

8. Coverage Matrix 자가 검증 감사

적재 직후 36개 전 스킬에 대해 브릿지 매핑을 감사하고, 미달 항목은 Vector RAG가 100% 충원(Strict 2-Pack Guarantee)하여 결손율 0.0%를 항시 보증합니다.

0-1. 아키텍처 패러다임 대조 분석: 레거시(실시간 GPT 호출) vs 현행(Full-Spectrum Vector RAG)

매 요청마다 외부 GPT API를 호출해 추천을 조립하던 과거 방식의 한계와, pgvector 시맨틱 검색으로 전환한 엔지니어링 진화 내역입니다.

2. 개인 성장 주기(Growth Lifecycle) 및 결손 심각도(Gap Level) 트랙

사내 역량 진단 결과(HIGH / LOW)에 따라 로드맵의 시작점과 보폭을 다르게 제어합니다.

STAGE 1 (A)

선수 지식 & 기초 체계

HIGH Gap 진단 시 필수 진입. 수학/알고리즘 및 컴퓨터공학 기초를 확립하는 온보딩 단계.

연계: K-MOOC 정규이론 (학위희망 시 학과 교과목)
STAGE 2 (B)

코어 이론 & 실무 개념

코어 메커니즘을 파악하고 정보나루 대출 1~2위 도서를 정독하며 개념을 완성하는 단계.

연계: 실대출 1위/2위 공인 스테디셀러 도서
STAGE 3 (C)

결손 실무 집중 해결

LOW Gap 진단 시 즉시 진입하는 패스트트랙 지점. 현업 적용 문제 해결 및 실무 프로젝트 단계.

연계: K-MOOC [매치업] 실습 + 실무 최적화 서적
STAGE 4 (D)

공인 역량 검증

보완된 역량을 국가기술 및 데이터 공인 자격증으로 사내외에 객관적으로 증명하는 마일스톤.

연계: 공인 자격증 2종 (SQLD/SQLP, 빅데이터분석기사 등)

3. 스킬-갭(Skill-Gap) 기반 Vector RAG 파이프라인 (Write & Read Flow)

지식 베이스 구축부터 임베딩 벡터화, 10ms 코사인 유사도 인출, 최종 AI 로드맵 조립까지의 데이터 흐름입니다.

PHASE 01 (Ingestion)
100% 실재 지식 베이스 적재
• 5대 공공 API 실재 데이터 수집
• 가짜 ID 및 비IT 오염 완전 소거
• RDB 마스터 테이블 정제 UPSERT
PHASE 02 (Vector Indexing)
5대 도메인 전수 벡터 임베딩
• text-embedding-3-small 1회 생성
• 1536차원 벡터 pgvector 영구 적재
• HNSW 코사인 인덱스 자동 가속
PHASE 03 (Semantic Retrieval)
10ms 코사인 유사도 인출
• 결손 스킬 벡터와 코사인 거리(<=>) 연산
• 부족분 실재 강좌·도서·자격증 자동 충원
• Strict 2-Pack 패키지 완성 (결손 0%)
PHASE 04 (Augmented Generation)

6. 추천 엔진 핵심 단일 SQL 쿼리 & Full-Spectrum Vector RAG 인출 엔진

로컬 DB B-Tree 인덱스로 1차 조인하고, 매핑 부족 시 pgvector 코사인 거리(<=>) 연산으로 실재 강좌·도서·자격증·학과를 10ms 만에 100% 보충합니다. 

-- ==============================================================================
-- [10ms 초저지연 RDB 큐레이션 쿼리] 유저 결손 스킬(gap_level 포함) 기준 도메인 추출
-- ==============================================================================
SELECT
    st.skill_id,
    st.name AS 결손_스킬명,
    st.category AS 기술_트랙,
    usg.gap_level AS 결손_심각도, -- 'HIGH' (풀트랙 A->D) vs 'LOW' (패스트트랙 C->D)
    m.title AS 연계_학과명,
    m.curriculum AS 학과_교과목,
    c.title AS 추천_강좌명,
    c.is_matchup AS 매치업_여부,
    c.org_name AS 강좌_개설기관,
    c.url AS 강좌_링크,
    b.title AS 추천_도서명,
    b.author AS 도서_저자,
    b.loan_count AS 도서_대출수,
    cert.title AS 자격증명,
    cert.provider AS 자격증_기관,
    cert.test_subjects AS 출제과목
FROM user_skill_gap usg
JOIN skill_tags st ON usg.skill_id = st.skill_id
LEFT JOIN major_skill_map msm ON st.skill_id = msm.skill_id
LEFT JOIN majors m ON msm.major_id = m.major_id
LEFT JOIN course_skill_map csm ON st.skill_id = csm.skill_id
LEFT JOIN courses c ON csm.course_id = c.course_id
LEFT JOIN book_skill_map bsm ON st.skill_id = bsm.skill_id
LEFT JOIN books b ON bsm.isbn = b.isbn
LEFT JOIN cert_skill_map cert_sm ON st.skill_id = cert_sm.skill_id
LEFT JOIN certifications cert ON cert_sm.cert_id = cert.cert_id
WHERE usg.user_id = %s
ORDER BY st.skill_id, b.loan_count DESC NULLS LAST;

-- ==============================================================================
-- [Vector RAG 시맨틱 충원 쿼리] 직접 매핑 부족 시 코사인 거리(<=>) 기반 초고속 충원
-- ==============================================================================
SELECT course_id, title, is_matchup, org_name, url
FROM courses
WHERE embedding IS NOT NULL AND POSITION('search' IN url) = 0
ORDER BY embedding <=> %s::vector LIMIT 8;
[Full-Spectrum Vector RAG & Strict 2-Pack 보장 원칙]
1. Direct Clamping: 단일 조인 결과에서 직접 매핑된 도서 상위 2권(대출순), 강좌 2개, 자격증 2개를 1순위로 배치합니다.
2. Vector RAG 충원: 매핑된 콘텐츠가 2개 미만일 경우, recommendation_service.py가 pgvector 코사인 거리(<=>) 연산을 통해 의미가 가장 밀접한 실재 콘텐츠를 10ms 만에 충원하여 무조건 결손율 0.0%의 2종 패키지를 완성합니다.
3. Zero-Hallucination: 외부 LLM이 임의로 생성한 가짜 URL이 아닌, DB에 이미 검증된 실재 K-MOOC 상세 ID(detail/{id}) 및 공인 도서/자격증만 서빙되므로 링크 깨짐이 원천 차단됩니다.

초저지연 10ms 쿼리 서빙

런타임 프롬프트 호출 대신 로컬 PostgreSQL pgvector HNSW 인덱스를 활용하여 10ms 이내에 시맨틱 큐레이션을 완수합니다.
