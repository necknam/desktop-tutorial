# 한국수자원공사 규정 통합 전처리 전달본

인재개발규정을 포함한 확보 규정 **28건·861쪽**을 한 묶음으로 전달한다. 앞으로는 이 통합본의 `data/`와 `schema.json`을 사용한다. 기존 추가 규정·인재개발규정의 개별 전달본은 작업 이력이다.

## 1. 사용할 파일

| 위치 | 용도 |
|---|---|
| `data/*.json` | 9개 테이블의 통합 행. 원문 보정이 반영된 주 데이터 |
| `data/*.csv` | 동일 행의 표 형식 보조 파일. `\N`은 NULL, JSON 값은 문자열 |
| `schema.json` | 9개 테이블·85개 필드·17개 외래키의 제안 계약 |
| `answer_guidance.json` | 사용자가 수용한 정보 부족·기한·승진일·평정 안내 방향. 규정 원문과 구분하여 사용 |
| `delivery_config.json` | 일반직 가상 직원 5명 우선 범위, 질문일 기준, 후속 검토 범위 |
| `source/` | 원본 PDF 28건. 해시로 원본 동일성 확인 |
| `raw/` | 원문 쪽별 추출과 자동 검출 표의 보존 자료 |
| `보정/` | 전사·교육표 보정·사용자 확인 근거. 생성 당시 상태는 이력이며 통합 적용은 아래 보고서 기준 |
| `report/integration_ledger.json` | 추가한 보정 행, 교체한 교육표 본문, 대체 표시한 자동 추출 조각, 새로 연결한 참조 |
| `report/validation.json` | 필수값·ID·외래키·출처·내용 해시의 실제 검사 결과 |
| `report/general_staff_priority_checks.json` | 일반직 교육·인사 상담의 우선 질문 근거 연결 검사 |
| `report/remaining_reviews.json` | 원문 확보 및 후속 검토 항목 |
| `build_delivery.py` | 이 묶음만으로 `data/`를 다시 만드는 코드. DB/API 접속 없음 |
| `package_delivery.py` | 외부 비교 원문을 제외하고 전달 ZIP을 만드는 코드 |
| `provenance/` | 재생성 입력과 작업 이력. 원래 교육표 추출 내용도 여기에 보존 |

`provenance/external_sources/`의 법령·예규·지침은 **로컬 교차 검증용**이다. `data/`의 규정 28건, `source/`의 공사 원문 28건, 검색 조각에는 넣지 않았고 V08부터 전달 ZIP에서도 제외한다. 외부 자료를 전처리·검색 대상으로 추가하려면 별도 사용자 검토와 결정이 필요하다.

독립 DB 스키마 `hr_regulation_pilot`을 생성할 필요는 없다. 이 전달본의 `schema_name`은 NULL이다. `schema.json`은 규정 데이터의 필드·연결 계약이며, 실제 팀 DB의 종류와 통합 테이블 구조가 정해진 뒤 생성·적재 방식을 확정한다. 이 전달본은 팀 DB를 변경하지 않는다.

## 2. 이번 통합에서 반영한 내용

- 동일 기관 ID를 한 행으로 합치고 ALIO 기관 코드 `C0221`을 유지했다. ALIO 코드이며 범정부 공통 코드로 단정하지 않는다.
- 직제규정 PDF 27쪽 기구표의 표시 명칭 86곳, PDF 28쪽 정원표 10행, PDF 29~36쪽 별표4 분장업무 21행·번호 업무 165개를 전사해 데이터와 검색용 글 조각에 반영했다. 명칭 86곳에는 직위·의결기구 및 반복 표기도 포함된다.
- 앞선 설명에서 분장업무를 별표3으로 표기한 오류를 원문 PDF29쪽의 **별표4(제9조제3항 관련)**로 정정했다.
- 부서명 4개의 사용자 확인과 원문 행의 업무·소관부서 목록을 함께 보존했다. 업무 하나를 특정 부서·직원에게 배분하지 않았다. 기구표 지휘선의 상하관계 상세 구조화는 후속 검토다.
- 인재개발규정 별표1의 기준학습시간 10개 열·주석 4개, 별표2의 대상군·역량별 24개 기준·주석 10개·개정 비교 6개를 반영했다. 별표3의 학습 블록 3개·학습 내용 20개·주석 3개·진행 표시를 반영했다.
- 직제규정 시행세칙 PDF46쪽 별표4의 일반직 직종·직렬 표 6행·정의 주석 2개를 보완했다. 1급·2급(갑)의 대시와 2급(을)의 직종·직렬 병합 칸을 보존했다.
- 한국수자원공사취업규칙 PDF9쪽 연차 기준 6개를 원문 값으로 구조화하고 기간 계산·저축 원문을 검색 문장에 연결했다. 삭제된 제33조의2제3항은 유효한 기준에서 제외했다.
- 유연근무제운영기준 PDF18쪽 별표6 원격근무 가능직무 표 6행을 보완했다. 병합된 업무 구분, 조직 구분, 적용대상과 세부 직무를 함께 보존하고 제28조 및 신청·승인 조항에 연결했다.
- 연봉규정 PDF15쪽 기준급 상하한 16개, 연봉규정시행세칙 PDF27~29쪽 직위별 고정액 8개·직무등급별 상하한 15개를 보존했다. 금액 39개는 원문의 천원 단위와 원 환산 값을 구분하며 직원의 실제 연봉으로 확정하지 않는다.
- 연봉규정시행세칙 별표3·3의2·3의3의 원문 쪽수를 PDF27·28·29쪽으로 분리했다. 부칙 PDF20쪽의 별표 참조를 별표 제목으로 잘못 나눈 2건도 원문 제2조의 연속 문장으로 복원했다.
- 통상근무자 월 시간외(휴일)근무 수당 지급한도 2개를 원문 값으로 정리했다. 제12조의 주간 근무 제한과 특별한 경우의 문구를 함께 연결했다.
- 취업규칙 PDF27쪽 경조사휴가 8행·주석2개, PDF28쪽 사무외출 차감2개, PDF8쪽 장기재직휴가2개를 정리했다. 거리 가산·기간 계산·부칙 적용례·진단서 예외를 관련 원문으로 함께 연결했다.
- 원래 교육표·직종직렬표·원격직무표·보수표·휴가표의 자동 추출 본문은 `provenance/base_tables.json`에 보존했다. 통합 원문 항목에는 보정 본문을 넣고, 기존 자동 추출 검색 조각 11개에는 `superseded`를 표시했다.
- 별표2의 과정 목록을 문장으로 만들 때 `None`으로 출력되던 오류를 보정했다. 과정명과 하위 분야를 모두 보존하며 공란·대시·별도 기준을 구분한다.
- 원문 제목과 일치하는 조번호 130개를 대조해 `제10의2조` 같은 위치 표시를 `제10조의2` 형식으로 보정했다. 원문 본문과 기존 ID는 보존했다.
- 제28조제4항의 후속 번호 목록 누락은 원문과 구분한 검토 메모로 검색 문장에 표시했다. 교육경비 회수 기준을 제27조에서 추정하여 채우지 않는다.
- 필수교육 기준 조각에 관련 원문 주석을 함께 넣고 각각의 출처를 연결했다. 여러 출처를 가진 조각이 있으므로 `rag_chunk`와 `rag_chunk_source`의 행 수는 같지 않을 수 있다.
- 통합으로 확인된 참조 규정명은 연결했다. 이름 연결은 대상 개정본·조항·준용 범위 확정을 뜻하지 않는다.
- 인사규정 PDF5쪽 제23조의 최소 승진기간 7개를 원문 값으로 구조화했다. 최소기간 검색 문장에는 제22조 승진 원칙, 제24조 임용방법, 제26조 승진 제한의 원문을 함께 연결했다. 제26조의 휴직 예외에는 제31조의 휴직 종류 원문을 연결했다.

## 3. 일반직 상담 우선 검토

일반직 가상 직원 5명의 상담 범위는 사용자 확인에 따라 AI본부의 AI혁신처·디지털관리처·AI데이터센터와 경영부문의 인재경영실·노사협력처·재무관리처·정보보안처·비상계획처다. 예비 소속·직무는 **디지털관리처의 전산 업무**, **인재경영실의 행정 업무**다. 5명 모두 부서장이 아닌 팀원이며 교대근무하지 않는 직원으로 우선 검토한다. 가상 직원의 직급 후보 범위는 사용자 선택에 따라 **일반직 3~5급**으로 기록했다. 직원별 직급·인원 배분·재직 및 교육 이력은 추후 가상 데이터 생성 시 정하며, 현재 직원 데이터는 생성하지 않았다. 팀원 여부와 직급은 별도 조건이다.

직종·직렬 후보는 직제규정 시행세칙 PDF46쪽 별표4의 일반직 3~8급 구분을 근거로 한다. 이 표의 전산 직렬은 특수기술 직종이고 행정 직렬은 행정 직종이다. 따라서 선택한 3~5급은 표의 범위에 포함된다. 인재개발규정 별표1의 3·4·5급 학습시간 행과 별표2의 해당 직급 대상 열도 보정 자료에 있다. 가상 직원의 계획에 쓰는 후보이며 실제 직원의 직렬·교육 의무를 부서명이나 직급만으로 확정하지 않는다.

추후 멘토 또는 강사를 가상 부서의 상급자(예: 팀장)로 추가할 가능성이 있다. 직제규정 시행세칙 PDF47쪽 별표5를 화면으로 확인했으며, 팀장은 2급(을)·3급 직위 후보에 적혀 있다. 같은 세칙 제3조의2는 직급과 직위를 분리하여 운영할 수 있다고 한다. 현재 5명의 팀원 설정은 유지하며 상급자 데이터는 만들지 않았다. 실제 가상 프로필을 만들 때 직급·팀장 직위·부서장 해당 여부를 각각 설정하고, 부서장 제한이나 승인 권한을 팀장이라는 호칭만으로 자동 적용하지 않는다.

이는 **원문 근거 연결 검사**다. 실제 직원의 교육 의무·기한·점수 계산, 임베딩·RAG 검색·답변 검사를 실행한 것은 아니다.

직원 정보가 입력되면 직급, 직무분류, 임명·호칭 변경일, 마지막 승진일과 승진 직급, 채용 유형, 교육·휴직·복귀·승인 이력을 확인해야 한다. 모르는 값은 0·미이수·면제로 바꾸지 않는다. 미승진자의 마지막 승진일 공란은 정상일 수 있으며 기록 미확인과 구분한다.

교육표의 ‘대상 구분’은 원문 표의 구분이다. 예를 들어 임금피크 상태를 실제 직원 테이블의 직군으로 자동 등록하지 않는다. 교육 학습 내용의 글머리표 수를 개인의 필수 과정 수로 확정하지 않는다.

## 4. 적용과 검색 상태

- 상담 기준일은 질문하는 날의 한국시간 날짜다. 다운로드일이나 전처리일로 고정하지 않는다.
- 일반 시행일과 조항·별표의 예외 적용일을 구분한다. 제10조 제3항의 2028-01-01 예외 시행일은 유지했다.
- `regulation_scope`의 조건 원문은 보존했다. 직원별 자동 적용 조건은 아직 확정하지 않았다.
- `promotion_minimum_duration`의 `condition_json`은 원문의 직급·기간 값과 단위 환산만 담는다. `structure_kind=source_values_only`이며 개인의 승진 가능 여부·날짜를 계산하는 규칙이 아니다. 상세 입력은 `보정/일반직_승진검토_V01/승진_검토데이터.json`에 있다.
- `annual_leave_source_criterion`도 원문의 조건·일수·상한을 보존하는 값이다. 개인의 부여·잔여 연차를 계산하는 규칙이 아니며 입력은 보정/취업규칙_연차검토_V01/연차_검토데이터.json에 있다. 원격직무 표의 적용대상 역시 원문 표기이며 실제 직원의 원격근무 가능 판정과 구분한다.
- `flexible_work_source_criterion` 11개와 `salary_status_source_criterion` 8개는 공사 원문의 조건만 구조화한 것이다. 집약근무의 직무 예시가 신청 자격을 넓힌다고 보지 않으며, 개인의 승인·지급액은 계산하지 않는다.
- `regulation_scope.review_status`의 `source_deleted_not_applicable`은 원문에 본조 삭제가 명시된 과거 적용범위다. 현재 직원의 적용 조건으로 사용하지 않는다.
- `needs_review`: 검색 활성화 전 검토 상태. `not_for_answer`: 삭제 조문 등 답변 사용 제외. `superseded`: 보정 내용으로 대체된 자동 추출 조각.
- 임베딩 모델·벡터는 미생성 상태이며 검색 후보를 활성화하지 않았다. 실제 검색·답변 품질은 팀의 연결 단계에서 검사한다.
- 일반직 직원이 기간제근로자·청원경찰 등의 규정을 질문할 수 있으므로 모든 규정 자료를 유지한다. 질문 주제 검색과 질문자 본인에게 적용되는지는 각각 확인한다.

## 6. 다시 만드는 방법

Python 3.11 이상에서 이 폴더의 `build_delivery.py`를 실행한다. 별도 패키지는 필요하지 않다. `provenance/base_tables.json`과 `보정/`을 읽고 보정·참조 연결·검증 후 `data/`, 안내 기준, 검사 보고서를 다시 쓴다. 원본 PDF·기존 개별 작업 폴더·DB는 변경하지 않는다.

입력 → 원문 보정과 출처 연결 → 단일 JSON/CSV 전달 행의 순서다. CSV를 직접 수정하면 재생성 시 반영되지 않는다. 원문·보정 입력에 새 검토 내용을 기록한 후 다시 생성한다.

## 7. 재개 위치와 보존

2026-10-13 저녁 사용자 요청으로 작업을 재개했다. 현재 관리 대상은 이 통합 폴더 한 곳이다. 이전 단계의 파일을 다시 수정하거나 이미 확인한 항목을 재질문하지 않는다.

현재 생성물은 구조·출처 검사 62개, 우선 상담 근거 사례 35개가 통과했다. 반복 생성 일치 여부는 현재 `report/rebuild_check.json`의 상태를 확인한다. 검사 범위는 원문 근거와 전달 데이터의 연결이며 실제 상담 답변 검사는 아니다.

최근 사용자 검토 반영: 최소 승진기간과 실제 승진 여부의 구분, 전산직렬의 현장근무기간 예외, 휴직 사유·기간의 확인, 경력직 예외의 채용 직급 범위를 확인했다. 네 항목의 사용자 답변은 `provenance/user_review_decisions.json`에 기록했다. 개인별 승진 판정·날짜 계산은 구현하지 않았다. 인재개발규정 PDF21쪽의 교육 분야 연결 자료는 기관 추가 자료가 필요한 항목으로 유지한다.

이번 보완에서 유연근무 유형별 조건과 휴직·신분변경 보수 조건을 공사 원문으로 검토했다. 기관의 별도 휴가 운영 절차와 다태아 기준의 적용 관계는 자료가 제공될 때 재검토한다. 다른 직군 상세 조건, 위임전결 대형 표, 기구표 지휘선 관계, 사용자 보류 OCR도 현재 작업 범위에서는 제외한다. 현재 전달 ZIP V10에는 이 범위 조정과 가상 직원 3~5급 후보 설정이 반영되어 있고 외부 비교 원문은 제외된다. V01~V09 ZIP은 이전 시점의 보존본이며, V07에는 외부 비교 자료 5개가 들어 있으므로 새 전달용으로 사용하지 않는다.

연차 검토도 현재 폴더에 반영했다. 한국수자원공사취업규칙 PDF9쪽 제33조의2의 유효한 원문 기준 6개를 값으로 보존하고 삭제된 제3항은 제외했다. 연차 부여·기간 계산·저축 조항을 검색 문장에서 함께 연결했다. 사용자는 연차 예외를 함께 보존·안내하는 방향을 수용했고, 연차저축의 별도 노사합의서·운영 안내는 현재 없다고 확인했다. 개인 연차 계산과 상세 신청 절차는 미확정이다.

유연근무 검토: 가상 직원 5명을 부서장이 아닌 팀원으로 우선 검토하는 방향을 사용자 확인했다. 실제 직원 데이터는 생성하지 않았다. 신청·승인 원칙과 일반·유형별 신청 단위, 원격근무 가능직무 및 부적합 조건을 원문으로 연결했다. 부서명이나 팀원 직책만으로 원격근무 가능 여부를 확정하지 않는다.
