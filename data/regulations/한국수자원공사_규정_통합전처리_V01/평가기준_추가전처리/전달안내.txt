한국수자원공사 규정에 근거한 평가 기준 데이터 V01
작성 기준일: 2026-10-14

1. 이번에 정리한 범위
평가 기준·양식 11건, 항목 70건, 규정 근거 연결 172건이다.
대상 테이블은 evaluation_result_schema, evaluation_item_definition,
evaluation_schema_source 3개이며 설계 초안의 37개 컬럼과 일치한다.
현재 일반직 행정·전산 3~5급과 향후 상급자 후보 2급(을)의 참고 기준을 구분한다.
2급(을) 참고 기준이 실제 팀장 직급·평정자·권한 배정을 뜻하지 않는다.
직원별 인적 정보·평가 결과·교육 이수 기록은 생성하지 않았다.

2. 기준 묶음
종합근무평정: 3~5급, 2급(을) 참고 (2건)
근무성적평정: 3급, 4·5급, 2급(을) 참고 (3건)
교육훈련평정: 2급(을), 3급, 4급, 5급 (4건)
경력평정: 3~5급 (1건)
가감평정: 2급(을)·3~5급 참고 (1건)

3. 파일 사용
data/*.json은 구조화된 기준 행이다. data/*.csv는 같은 내용을 UTF-8 BOM으로 내보낸 입력 자료다.
CSV의 빈칸은 NULL이며 JSONB 컬럼은 JSON 문자열이다. 원자료의 미확인을 0으로 바꾸지 않는다.
CSV 3개는 JSON 3개와 왕복 값이 일치함을 확인했다.
schema.json은 기준 3개 테이블의 컬럼·자료형·연결 계약이며 아직 실제 DB에 적용한 DDL이 아니다.
기관·규정 근거 ID는 규정 전달본 V10을 재사용한다. 스킬 ID는 전부 NULL로 두었다.
manifest.json에서 규정 개정본·조항·원문 PDF 페이지·해시와 데이터 해시를 확인한다.
validation.json은 로컬 자료 검사 결과이며 팀 DB 통합 또는 상담 시스템 시험 결과가 아니다.

4. 점수 해석 시 주의할 내용
근무성적 3급과 4·5급의 하위 항목 합계는 각각 50점이다. 상위 집계와 하위 항목을 함께 더하지 않는다.
등급 분류는 제29조의8과 제35조의2를 연결했다. 다른 평정 종류의 42점·36점을 자동 연결하지 않는다.
교육훈련 산식은 A×[0.6×(B/C)+0.4×(D/E)]이다. A는 2급(을)10점, 3~5급25점이다.
연간 기준학습시간은 2급(을)48시간, 3급64시간, 4급80시간, 5급112시간이다.
연간 최대 학습 인정시간200시간과 인재개발담당부서 의무시간40% 이상은 교육 기준이다.
이를 교육 점수25점 자동 상한이나 모든 학습의 자동 인정으로 해석하지 않는다.
필수교육의 이름·분야는 원문대로 보존하되 실제 대상 과정 수 E와 과정 ID를 추정하지 않았다.
미확인 C·E, 분모0, 시간 미기록, 리더교육 기록 부재는 개인 결과 생성 시 계산 가능 여부를 따로 판단한다.
경력 별표6의 36개 값은 기본경력을 포함한 총점이다. 기본3.5점을 다시 더하지 않는다.
가점·감점은 개인 적용 조건과 유리/불리한1개 선택, 동일 사안 중복 제한을 확인한다.
삭제된 전산가점·현장근무가점 등의 옛 항목을 현행 기준으로 만들지 않았다.

5. 남은 사람 확인과 후속 작업
모든 행은 published_rule을 근거로 작성했으며 review_status=needs_review로 남겼다.
source_status=partial은 내부 세부 기준·개인 적용 정보까지 모두 확보했다는 뜻으로 쓰지 않기 위한 상태다.
일반 시행일은 V10에 보존돼 있으나 평가 기준의 항목별·과거 적용일은 임의 확정하지 않고 NULL로 둔다.
최신 사내 DB 설계와의 컬럼·상태 코드·기관 ID 매핑, 교육 인정정보의 저장 위치,
평정자·조회 권한과 학습 사용 동의 범위는 평가 설계 문서 6.4의 확인 목록을 따른다.
가상 직원 인적 정보 생성 시 개인 직급·재직/교육 이력과 평가 결과를 함께 만든다.
기관 내부 자료가 없는 세부 인정기준은 현재 확보 범위를 설명하고 미확인으로 유지한다.
상위 법령·비교용 외부 문서는 이번 기준 행, 규정 근거 연결 또는 전달 ZIP에 포함하지 않았다.

6. 재생성과 검사
Python 표준 라이브러리를 사용하며 DB 접속·INSERT·UPDATE·DELETE·검색 색인 생성을 수행하지 않는다.
ZIP을 푼 뒤 한국수자원공사_규정_통합전처리_V01 폴더에서 아래와 같이 실행할 수 있다.
python 평가기준_추가전처리/build_evaluation_criteria.py --regulation-bundle .
python 평가기준_추가전처리/validate_evaluation_criteria.py --regulation-bundle .
python 평가기준_추가전처리/test_criteria_validation.py --regulation-bundle .
첫 명령은 평가기준_추가전처리/data 및 manifest.json을 다시 작성한다.
실제 DB 생성·적재는 통합 담당자의 최신 설계 확인과 사람 검토 이후 진행한다.
