필수교육 기준 확인 필요

현재 확보한 인재개발규정 별표 2에는 전문직의 리더·직무역량 필수교육 과정이 공란으로 기재되어 있습니다.

공통역량 교육은 기관이 별도 방침으로 정하여 시행합니다. 해당 연도의 교육 안내를 확인해 주세요.

개인의 목표와 업무에 맞춘 성장계획과 교육 추천은 계속 이용할 수 있습니다.

4급 리더교육 · 개인별 적용 방향

사용자가 수용한 보정 방향입니다. 직급·호칭·임명 이력에 맞는 교육 후보를 확인하고, 과정별 이수 완료와 이수 간주를 구분합니다.

확인된 상황교육 후보안내 방향
4급 대리로 새로 임명됨신임대리확인할 교육과정으로 제시하고 기관의 과정별 대상 안내와 대조
4급 과장으로 호칭이 변경됨신임과장확인할 교육과정으로 제시하고 기관의 과정별 대상 안내와 대조
해당 과정의 이수 내역이 확인됨해당 과정별 확인해당 과정 이수 완료로 표시하고 중복 참여 안내를 줄임
경력직·고용전환 등 채용 당시 이수 간주 조건이 확인됨해당 과정별 확인실제 수강과 구분하여 해당 임명 당시 교육의 이수 간주로 표시
직급만 있고 호칭·임명 이력이 없음해당 과정별 확인두 과정을 보여주되 개인별 대상은 확인 필요로 표시

직원 정보에서 확인할 내용: 직군·직급, 현재 호칭, 임명·호칭 변경의 종류와 일자, 과정별 교육 이수 내역, 경력직·고용전환 등 채용 유형

  • 대리 교육 이수를 이후 과장 호칭 변경에 따른 교육까지 완료한 것으로 확대하지 않는다.
  • 경력직 등의 이수 간주는 채용·임명 당시 리더교육을 기준으로 확인한다.
  • 이수기한 안내에는 제7조 제4항과 부칙 적용례, 임명·호칭 변경일 및 복귀·휴직 정보를 함께 확인한다.
  • 과정 배정·기한 산정의 실제 서비스 구현은 포함하지 않은 보정안이다.

해당 과정의 이수 내역과 올해 교육 대상 안내를 확인해 주세요.

등록된 인사정보에서 4급 대리 임명 내역이 확인됩니다. 별표 2의 4급 리더교육에는 ‘신임대리’ 과정이 기재되어 있습니다.

해당 과정의 이수 내역과 올해 교육 대상 안내를 확인해 주세요.

리더교육 대상 확인 필요

현재 등록된 정보만으로는 개인에게 해당하는 과정을 구분하기 어렵습니다. 임명·호칭 변경 내역 또는 기관의 교육 대상 안내를 확인해 주세요.

승진일 기준 · 개인별 적용 방향

사용자가 수용한 직무역량 개정 기준의 안내 방향입니다. 미승진자의 마지막 승진일은 공란으로 유지하며, 여러 번 승진했다면 마지막 승진일이 현재 직급으로 승진한 날짜인지 대조합니다. 직군·직급과 해당 직급의 승진 이력을 확인하며 개인별 교육 면제를 자동 확정하지 않습니다.

일반직 4급은 2019-01-01 이후, 일반직 2급(을)·3급은 2010-12-01 이후 해당 직급 승진자라는 원문 조건 C-07을 참고합니다.

확인된 상황안내 방향
현재 직급으로 승진했고 승진일이 해당 기준일 이상으로 확인됨C-07에 따른 개정 기준 적용 대상으로 안내하고 종전 교육 이수 내역을 함께 확인
현재 직급으로 승진했으나 승진일이 해당 기준일 이전으로 확인됨종전 교육기준이나 추가 적용 규정을 확인. 교육 면제로 확정하지 않음
승진한 적이 없어 마지막 승진일이 공란인 것으로 확인됨마지막 승진일을 NULL로 유지하고 현재 직급의 채용·임용에 따른 교육기준을 확인
현재 직급으로 승진했는지 확인되지 않음승진 이력 확인 필요로 안내. 기록이 없다는 이유로 승진하지 않았다고 확정하지 않음
현재 직급으로 승진한 사실은 확인됐지만 승진일은 확인되지 않음해당 직급 승진일 확인 필요로 안내. 입사일·호칭 변경일·직급 시작일로 임의 대체하지 않음
마지막 승진일은 있으나 그때 승진한 직급이 현재 직급과 다르거나 확인되지 않음마지막 날짜를 바로 대입하지 않고 현재 직급으로의 승진 여부·직급 변경 사유를 확인

직원 정보에서 확인할 내용: 현재 직군·직급, 마지막 승진일(승진한 적이 없으면 공란), 마지막 승진으로 오른 직급 또는 현재 직급의 시작 사유, 승진일이 공란인 이유(승진 이력 없음·기록 미확인)를 원자료에서 확인

  • 직군·직급이 C-07의 대상인지 먼저 확인한다. 다른 직군·직급의 교육 의무는 해당 기준에서 별도로 확인한다.
  • 여러 번 승진했다면 마지막 승진일이 현재 직급으로 승진한 날짜인 경우 그 값으로 C-07을 확인할 수 있다.
  • 마지막 승진의 직급이 현재 직급과 다르면 마지막 날짜만으로 C-07을 판단하지 않는다.
  • C-07은 직무역량 개정 기준의 조건이다. 리더교육 대상·기한은 제7조 제4항과 부칙에서 별도로 확인한다.
  • 실제로 승진하지 않은 경우와 승진 여부 또는 승진일의 기록이 부족한 경우를 구분한다.
  • 승진하지 않은 경우를 승진일 누락 오류로 처리하지 않으며, 채용·임용 적용 기준을 확인한다.
  • 승진일 조건에 해당하지 않거나 정보가 부족하다는 사실만으로 필수교육 면제를 확정하지 않는다.
  • 안내 방향을 수용한 보정안이다. 직원별 자동 판정이나 전체 규정 검토 완료를 의미하지 않는다.

직원 안내문 예시

개정 교육기준 적용 대상

등록된 현재 직급의 승진일이 해당 기준일 이상으로 확인됩니다. 별표 2의 승진일 조건에 따른 개정 직무역량 교육기준을 참고할 수 있습니다.

종전 교육 이수 내역과 인정 조건을 함께 확인하여 추가 교육이 필요한지 살펴보겠습니다.

교육기준 적용 확인 필요

현재 직급의 승진일이 별표 2의 개정 기준 적용일보다 이전으로 확인됩니다.

종전 교육기준이나 추가 적용 규정을 확인해야 합니다. 이 사실만으로 교육 면제가 되는 것은 아닙니다.

채용·임용에 따른 교육기준 확인 필요

승진한 이력이 없는 것으로 확인되어 마지막 승진일은 공란으로 유지합니다. 정상적인 공란이며 날짜를 새로 입력할 필요가 없습니다.

현재 직급을 시작한 채용·임용 경위와 적용되는 교육기준을 확인하겠습니다. 승진하지 않았다는 이유만으로 필수교육 면제로 처리하지 않습니다.

승진 이력 확인 필요

현재 등록된 정보만으로는 해당 직급으로 승진했는지 확인하기 어렵습니다.

승진 기록이 없다는 것과 실제로 승진하지 않았다는 것은 다릅니다. 직급 변경 사유와 인사발령 이력을 확인해 주세요.

승진일 확인 필요

현재 직급으로 승진한 사실은 확인되지만 승진일이 확인되지 않습니다.

개정 교육기준의 적용 여부를 확인하려면 해당 직급의 승진일이 필요합니다. 입사일이나 직급 시작일을 승진일로 임의 사용하지 않습니다.

현재 직급의 승진 기준 확인 필요

마지막 승진일은 등록되어 있지만 해당 승진이 현재 직급으로의 승진인지 확인이 필요합니다.

현재 직급과 마지막 승진의 직급 또는 직급 시작 사유를 대조한 뒤 적용 기준을 확인하겠습니다.

종전 직무이해Ⅱ · 이수 인정 안내

사용자가 수용한 안내 방향입니다. 원문 조건 C-08의 행정·기술 양 분야 이수 여부를 확인하며, 실제 수강과 종전 교육에 따른 이수 인정을 구분합니다.

확인된 상황안내 방향
종전 행정·기술 분야 이수가 모두 확인됨C-08에 따른 개정 직무이해Ⅱ 전체 이수 인정으로 안내. 개정 과정을 실제 수강한 기록과 구분
한 분야 이수와 다른 분야 미이수가 확인됨전체 이수 인정 조건은 충족하지 않음. 기존 이수 내역을 보존하고 개정 과정의 부분 인정 기준은 별도 확인
한 분야 이수는 확인되지만 다른 분야의 기록은 미확인인정 조건 확인 필요로 안내. 기록 미확인을 미이수로 단정하지 않음
과정명만 있고 분야별 이수 내역이 없음행정·기술 분야별 이수 내역을 확인한 뒤 전체 인정 여부를 검토
종전 직무이해Ⅱ에 해당하는 교육인지 불명확과정명·운영 시기·기관의 인정 내역을 확인

직원 정보에서 확인할 내용: 종전 교육과정의 명칭·운영 시기, 행정 분야 이수 내역, 기술 분야 이수 내역, 기관의 별도 인정 내역

  • 행정·기술은 종전 교육 분야다. 현재 부서나 직군으로 이수 여부를 판단하지 않는다.
  • 다른 분야의 미이수가 확인된 경우와 해당 분야 기록이 확인되지 않은 경우를 구분한다.
  • 종전 이수 기록을 보존하고 실제 수강과 경과규정에 따른 이수 인정을 따로 표현한다.
  • 한 분야 이수를 개정 과정의 어느 세부 분야에 부분 인정할지는 별도 기준 확인 전 확정하지 않는다.
  • C-08 인정을 직무이해Ⅲ·Ⅳ까지 확대하지 않는다.

직원 안내문 예시

종전 교육에 따른 이수 인정

종전 직무이해Ⅱ의 행정·기술 분야를 모두 이수한 내역이 확인됩니다.

별표 2의 C-08 인정 조건에 따라 개정 직무이해Ⅱ를 모두 이수한 것으로 볼 수 있습니다. 종전 이수 내역은 그대로 보존합니다.

전체 이수 인정 조건 미충족

종전 직무이해Ⅱ의 한 분야 이수와 다른 분야 미이수가 확인됩니다. 양 분야 이수에 따른 전체 인정 조건은 충족하지 않습니다.

이수한 분야의 기록은 보존합니다. 개정 과정에 대한 부분 인정 여부는 기관의 추가 기준을 확인해야 합니다.

교육 이수 인정 조건 확인 필요

종전 직무이해Ⅱ의 한 분야 이수는 확인되지만 다른 분야 이수 내역은 현재 등록된 자료에서 확인되지 않습니다.

기록이 확인되지 않는다는 이유로 미이수로 표시하지 않습니다. 다른 분야의 이수 내역을 함께 확인해야 전체 인정 여부를 판단할 수 있습니다.

분야별 이수 내역 확인 필요

종전 직무이해Ⅱ의 과정명은 확인되지만 행정·기술 분야별 내역이 구분되어 있지 않습니다.

기관의 교육 이력에서 두 분야의 이수 내역을 확인해 주세요.

종전 교육과정 확인 필요

등록된 교육이 C-08의 종전 직무이해Ⅱ에 해당하는지 확인이 필요합니다.

과정명과 운영 시기, 기관의 인정 내역을 대조한 뒤 이수 인정 여부를 확인하겠습니다.

2. 주석·적용 조건

교육과정명과 구분해 저장합니다. 날짜 조건은 승진일 또는 평정 연도에 관한 내용이며, 규정 개정일과 구분합니다.

리더교육 이수기한 확인

확인된 교육 대상과 임명·변경일, 휴직·복귀 이력을 원문 기준에 대조하여 이수기한을 안내합니다.

해당 교육의 실제 이수 또는 이수 간주 내역도 함께 확인해 주세요.

리더교육 기한 확인 필요

현재 자료만으로는 해당 리더교육의 이수기한을 확정하기 어렵습니다.

임명·변경일, 시행 당시 교육 이력 또는 휴직·복귀 내역을 확인해야 합니다. 확인되지 않은 날짜나 연장을 임의 적용하지 않습니다.

리더교육 이수 내역 확인 필요

해당 교육의 이수 내역이 현재 자료에서 확인되지 않습니다.

규정 산식과 변수 정의 확인산식과 원문 위치를 안내. 실제 점수는 적용 대상·개인 입력값·세부 기준 확인 후 검토
교육 기록·인정시간·대상 과정 수 등이 확인되지 않음점수 확인 필요로 안내. 미확인 값을 0으로 바꾸지 않음
리더교육 이수 여부 또는 직군전환 적용 관계가 불명확함평정 대상 여부 확인 필요로 안내. 기록 미확인을 실제 미수료·평정 제외로 확정하지 않음
목표학습량 C 또는 대상 과정 수 E가 0으로 제공됨산식을 실행하지 않고 해당 값·적용 관계를 확인. 0점이나 면제로 바꾸지 않음

직원 정보에서 확인할 내용: 평정 기준일·적용 연도와 당시 적용되는 규정 개정본, 직군·직급·직급 재직기간과 기관에서 인정하는 근무연수, 평정 대상 여부와 리더교육 이수·이수 간주 내역, 직군전환 특례, 인정된 학습시간과 해당 직급의 기준학습시간, 해당 직원에게 적용되는 필수 직무교육 과정 목록과 대상 과정 수, 해당 직급 재직기간 중 확인된 과정별 이수·종전 이수 인정 내역, 세부 학습시간 인정·근무연수 계산·점수 상한·반올림 등 기관 기준

  • 질문하는 날은 상담의 규정 적용 기준일이다. 매년 평정 기준일과 같은 날짜로 취급하지 않는다.
  • 제41조의 리더교육 미수료와 직군전환 특례, 제7조의 기한·부칙 적용 관계는 함께 확인해야 한다.
  • 별표1에는 정기평정 기준일 10월31일과 기준일 전 1년간 평정 안내가 있다. 제42조의 직급 재직기간 누계 산식과 구분해 보존한다.
  • 별표1의 연간 최대학습인정시간 200시간은 학습시간 인정에 관한 원문이다. 평정 점수나 비율 상한으로 대신 사용하지 않는다.
  • 이수 비율은 현재 실무 역량 점수로 자동 변환하지 않는다.
  • 산식 저장과 관련 원문 연결만 수행했다. 실제 직원의 점수 계산·평정 제외 판정은 구현하지 않았다.
  • 제41조의 평정 대상·리더교육 미수료 조항·직군전환 특례를 모두 보존한다. 직원별 평정 대상 제외를 자동 판정하지 않는다.
  • 직무이해Ⅱ의 4개 분야 표기만으로 직원별 E를 일괄 4로 확정하지 않는다.
  • 별표2 C-09의 2025년 교육훈련평정 반영 안내와 현재 확보한 세칙 개정본의 적용 시점을 구분한다. 과거 평정은 당시 적용 개정본 확인이 필요하다.
  • 제42조·제43조가 인재개발규정의 세부사항을 참조한다. 산식 확인을 상세 인정기준 확보와 동일하게 취급하지 않는다.
  • 연간 학습인정시간 상한과 평정 점수·비율 상한은 서로 다르다. 이 자료에서 점수 상한·반올림을 임의로 채우지 않는다.
교육훈련평정 산식 안내

인사규정시행세칙 제42조는 학습시간 달성 비율 60%와 필수 직무교육 이수 비율 40%를 반영하는 산식을 정하고 있습니다.

개인 점수를 확인하려면 평정 대상 여부, 인정된 학습시간, 해당 직원의 필수 과정 수와 이수 내역을 확인해야 합니다.

교육훈련평정 점수 확인 필요

현재 자료에서 점수 계산에 필요한 정보가 충분히 확인되지 않습니다.

확인되지 않은 기록을 0시간·미이수·0점으로 표시하지 않고, 필요한 교육 이력과 기관의 인정 기준을 확인하겠습니다.

교육훈련평정 대상 여부 확인 필요

리더교육 이수 또는 직군전환 특례의 적용 관계를 확인해야 합니다.

교육 기록이 보이지 않는다는 이유로 평정 대상에서 자동 제외하지 않습니다.

  • 제10조 전체의 시행일을 2028년으로 바꾸지 않는다. 제3항의 예외 시행일을 원문 항목 단위로 확인한다.
  • 2028년 이후 상담도 질문 당시 적용되는 개정본과 개인의 교육 이력·기한을 대조한다.
  • 원문에 제외할 수 있다고 되어 있으므로 시스템이 제외 결정을 대신 확정하지 않는다.

보정 JSON은 기존 별표2 노드 ID를 통해 원문과 연결할 수 있습니다. 이번에는 기존 ERD·테이블·자동 추출·검색 조각을 변경하지 않고 보정 데이터를 별도로 추가했습니다. 검토 후 DB 대응과 검색 반영을 진행할 수 있습니다.

사용자가 검토할 부분

  1. 전문직 공란 처리 방향과 직원 안내문: 사용자 의견 반영. 개별 교육 의무는 미확인.
  2. 4급 리더교육 적용 방향과 직원 안내문: 사용자 의견 반영. 임명·호칭 변경과 과정별 이수 내역을 함께 확인.
  3. 승진일 안내 방향: 사용자 의견 반영. 미승진자는 승진일 NULL이 정상이며 마지막 승진일이 현재 직급으로의 승진일인지 대조.
  4. 종전 직무이해Ⅱ C-08 안내 방향: 사용자 의견 반영. 실제 미이수와 기록 미확인을 구분하고 전체 이수 인정·부분 인정 확인을 구분.
  5. 리더교육 기한 안내 방향: 사용자 의견 반영. 본문과 부칙·복귀·연장 조건을 연결하고 근거 부족 시 확인 필요로 안내.
  6. 교육훈련평정 C-05: 관련 세칙 제41~43조와 산식·변수 정의를 연결. 정보 부족 시 점수 확인 필요 안내 방향을 사용자 의견에 따라 반영.
  7. 제10조 제3항: 2028-01-01 예외 시행일과 개인 이력을 확인한 후 조건부 안내. 실제 교육 대상자 자동 제외 판정은 보류.
  8. 나머지 주석 6개: 원문 명시 내용 대조. 2일의 시간 환산, 신입교육 중복 배정, 평정 연도의 날짜 변환, 임금피크 세부 과정 추정을 보류.
  9. 별표 3은 별도 보정 자료에서 단계·분야·평가를 확인. 상세 인정기준·개인별 적용·공식 해석 검토는 계속 유지.

원문 이미지와 보정표를 대조했습니다. HTML 구조 검사는 수행하며, 브라우저 렌더링 검증과 실제 DB 적재는 수행하지 않습니다. 별표 3은 이번 보정에 포함하지 않았습니다.
