2. Hub-and-Spoke 논리적 데이터 모델링 구조

중앙 실무 스킬 태그를 코어로 두고 도메인 및 사용자 진단을 N:M으로 바인딩한 계층적 설계입니다.

[Core Hub Entity]

skill_tags (중앙 표준)

36개 표준 실무 스킬의 고유 ID 및 기술 트랙, 1536차원 임베딩을 보유한 시스템 코어 기준 테이블.

[5대 Master Entities]

jobs · courses · books · certs · majors

공공 API에서 검증 수집된 실재 지식 베이스. 각 엔티티 고유 메타데이터와 시맨틱 벡터 저장.

[5대 Bridge Entities]

*_skill_map (5종 N:M)

복합 기본키(PK, FK)를 채택하여 도메인 간 다대다 관계를 3NF 정규화로 매핑한 무결성 브릿지.

[User Context Entities]

users · user_skill_gap

사번 기준 임직원 프로필, 목표 직무, 학위 희망 플래그 및 결손 심각도(HIGH/LOW) 진단 기록.

4. Full-Spectrum Vector RAG 스토리지 및 임베딩 규격

외부 별도 Vector DB를 배제하고 PostgreSQL 내부 확장을 채택한 배경 및 임베딩 텍스트 합성 명세입니다.

[In-Database pgvector 채택 엔지니어링 근거]
1. 트랜잭션 일관성(ACID): 외부 Vector DB(Pinecone 등) 사용 시 발생하는 RDB-Vector DB 간 이중 트랜잭션 불일치 위험을 원천 배제합니다.
2. 단일 조인 하이브리드 검색: 일반 관계형 테이블(`user_skill_gap`, `users`)의 B-Tree 필터링과 코사인 거리 연산자(`<=>`)를 단일 SQL 안에서 한 번에 실행 가능합니다.
3. 네트워크 레이턴시 최소화: 외부 벡터 서비스 왕복 네트워크 지연 없이 로컬 DB 엔진 메모리 상에서 10ms 이내에 탐색을 완료합니다.
[도메인별 임베딩 텍스트 합성 규격 (Synthesis Policy)]
• skill_tags: f"실무 스킬: {name} (기술 도메인: {category})"
• courses: f"온라인 강좌: {title} | 교육 내용: {syllabus_summary}"
• books: f"기술 도서: {title} (저자: {author})"
• certifications: f"공인 기술 자격증: {title} | 출제 과목: {test_subjects}"
• majors: f"대학 전공: {title} | 교과목 커리큘럼: {curriculum}"
• jobs: f"표준 직무: {title} | 직무 역량: {ncs_units}"

5. 이원화 인덱싱 및 쿼리 실행 최적화 전략 (Dual Indexing)

RDB 관계형 B-Tree 색인과 pgvector HNSW 근사 최근접 탐색 인덱스의 상호 보완 설계입니다.

인덱스 명칭 적용 대상 테이블 인덱스 유형 인덱싱 컬럼 및 연산자 성능 최적화 목적
idx_courses_embedding courses HNSW embedding vector_cosine_ops 강좌 코사인 거리(<=>) 10ms 초고속 탐색
idx_books_embedding books HNSW embedding vector_cosine_ops 도서 시맨틱 유사도 인출 가속
idx_certs_embedding certifications HNSW embedding vector_cosine_ops 출제과목 벡터 기준 자격증 1순위 매칭
idx_majors_embedding majors HNSW embedding vector_cosine_ops 커리큘럼 시맨틱 학과 추천 가속
idx_jobs_embedding jobs HNSW embedding vector_cosine_ops NCS 직무 역량 자동 바인딩 가속
idx_skill_tags_embedding skill_tags HNSW embedding vector_cosine_ops 스킬 간 의미론적 거리 측정 인덱싱
idx_user_skill_gap_user_id user_skill_gap B-Tree user_id ASC 유저별 결손 스킬 즉시 인출 (단일 스캔)
idx_books_loan_count books B-Tree loan_count DESC 도서 대출 순위 정렬 오버헤드 제거
idx_*_skill_map_skill_id 브릿지 5개 테이블 전수 B-Tree skill_id ASC 단일 조인 외래키 참조 속도 10ms 보장 
-- ==============================================================================
-- [10ms 초저지연 하이브리드 RAG 인출 실행계획]
-- 1. B-Tree 인덱스로 진단된 결손 스킬의 1536차원 벡터 스캔
-- 2. HNSW 인덱스를 통해 코사인 거리(<=>)가 가장 가까운 상위 8개 실재 강좌 인출
-- ==============================================================================
SELECT course_id, title, is_matchup, org_name, url
FROM courses
WHERE embedding IS NOT NULL
  AND POSITION('search' IN url) = 0 -- 500 에러 링크 배제 필터
ORDER BY embedding <=> %s::vector   -- HNSW vector_cosine_ops 연산자 활용
LIMIT 8;

6. 데이터 무결성 제약 및 멱등성 트랜잭션 제어

데이터 오염을 방지하는 외래키 캐스케이드 정책과 DO UPDATE SET 멱등성 트랜잭션 설계입니다.

[참조 무결성 (Foreign Keys)]

CASCADE & SET NULL

스킬 태그 삭제 시 매핑 브릿지 및 갭 진단은 동시 연쇄 삭제(CASCADE)되며, 직무 삭제 시 사용자 레코드는 보존(SET NULL)되어 고아 레코드를 원천 차단합니다.

[도메인 제약 (Domain Check)]

CHECK & UNIQUE 제약

CHECK (gap_level IN ('HIGH', 'LOW'))를 통해 심각도 값의 이상 입력을 차단하고, UNIQUE(user_id, skill_id)로 동일 임직원의 중복 갭 적재를 방어합니다.

[멱등성 제어 (UPSERT Strategy)]

ON CONFLICT DO UPDATE SET

배치 재실행이나 반복 평가 시 중복 PK 예외를 발생시키지 않고 최신 값으로 원자적 갱신을 수행하여 파이프라인의 100% 멱등성(Idempotency)을 보장합니다.
